# Profile avatars

Eight SHAREit character avatars selected and supplied by the user as a screenshot on 2026-10-19. Extracted programmatically at 196×196 without redrawing. Source images belong to their respective rights holders; no new license or ownership is asserted.

Only the eight PNG files were published, with user approval, in commit `5d4edfc2da3409a50ae610e600095021d68af82b` of https://github.com/yuriiDaniuk/sprout. The application stores immutable HTTPS URLs in Firebase photoURL. Bundled copies provide a fallback if those URLs cannot load.
